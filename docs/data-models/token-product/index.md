# Token Product

The Token Product Data Model describes a real product printing of a token, made up of one or more token faces.

- **Parent model:** [Card (Token)](/data-models/card/card-token/)
- **Parent property:** `tokenProducts`

## Model Properties

>

> ### tokenParts
>
> The token faces that make up the product. See the [Token Product (Part)](/data-models/token-product/token-product-part/) Data Model.
>
> - **Type:** `TokenProductPart[]`
> - **Introduced:** `v5.3.0`

> ### uuid
>
> The universal unique identifier (v5) generated by MTGJSON for the physical token product. It is derived from the product's faces and their face attributes only, so listings of the same physical token under different `tcgplayerProductId` values share a uuid, and the same product has the same uuid on every token it is listed under. Gold Stamped and plain versions of a token have different uuids.
>
> Derivation: for each entry in `tokenParts`, the part key is its `uuid` (or, if it has none, the compact JSON array `[faceId, faceName]`); each part becomes `[partKey, sorted faceAttribute (missing = [])]`; duplicate parts are removed and the rest sorted ascending; the list is serialized as compact JSON (no whitespace, non-ASCII unescaped, same as `JSON.stringify`) and hashed with uuid5 in the DNS namespace. For example, the BLC Eldrazi // Clue token hashes `[["3c0ee4a0-0554-5751-9425-fdcd54ec07fb",[]],["48394044-7565-5d50-a917-1fc2e26b8592",[]]]` to `313a62ae-628e-5e7e-88c1-4ab9b37f6f34`.
>
> - **Type:** `string`
> - **Introduced:** `v5.3.2`
